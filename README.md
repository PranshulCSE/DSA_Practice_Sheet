# DSA-Practice_sheet 📚

Daily DSA (Data Structures & Algorithms) practice repository — solving pattern-wise LeetCode problems as part of placement preparation.

## 🎯 Goal

Solve **80-85 questions**, organized pattern-wise, with a focus on:
- Understanding the core intuition behind each pattern
- Being able to recall the logic within a minute of seeing the question
- Writing clean, well-commented code for every solution

## 🗂️ Structure

Each solution file follows a consistent format:
- Problem description + example in comments at the top
- Clean, working code
- Time & Space complexity noted

Problems are grouped **pattern-wise** (e.g., Arrays & Hashing, Two Pointers, Sliding Window, Binary Search, etc.) so revision becomes fast and pattern recognition becomes second nature.

## ✅ Progress

### Arrays & Hashing 
> More patterns (Two Pointers, Sliding Window, Stack, Binary Search, Linked List, Trees, Tries, Heap, Backtracking, Graphs, DP, Greedy, Intervals, Math & Geometry, Bit Manipulation) coming up as practice continues.

## 🧠 Approach

For every problem, the following is captured before jumping into code:
1. **Problem understanding** — in simple terms with examples
2. **Pattern recognition** — what signals in the question point to a specific approach/data structure
3. **Logic/Intuition** — the "aha" trick that makes the solution click
4. **Code** — clean implementation with inline comments

## 🛠️ Language

Primary language used: **C++**
